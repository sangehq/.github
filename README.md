# sangehq/.github

> Organization-wide community health files and the org profile for the
> [sangehq](https://github.com/sangehq) organization.

The default `SECURITY.md`, `SUPPORT.md`, `CONTRIBUTING.md`, and
`CODE_OF_CONDUCT.md` here apply to every sangehq repository lacking its own.

`profile/README.md` renders at [github.com/sangehq](https://github.com/sangehq).
